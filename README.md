# シンプル台形補正
　直感的に扱えるシンプルなアプリ。
　斜めから映した写真を正面から撮ったように補正します。

## 【やり方】

1. **メディアの選択**
   📱 画面下部の **[Select]** から写真または動画を選んでください。

2. **編集画面への進み方**
   * **【写真の時】**
     選択した写真が表示されたら、**[Edit]** ボタンを押して次に進みます。
   
   * **【動画の時】**
     ▶️ 動画を再生し、ベストな瞬間で **[Capture]** を押してください。
     切り出した場面が表示されたら、**[Edit]** ボタンを押して次に進みます。
     ※ やり直す時は、**[Discard]** ボタンを押してください。

3. **台形補正（切り抜き範囲の指定）**
   🎯 4つの照準を合わせて、右上の **[Crop]** を押してください。

4. **プレビューの確認**
   補正された画像が表示されます。
   （※ 再度補正が必要な場合は、手順2から繰り返します。）

5. **比率の調整**
   📐 ドラッグして縦横の比率を自由に調整できます。

6. **画像の保存**
   完成した画像を **[Save]** ボタンで保存します。

7. **完了**
   「画像の保存に成功しました」というアラートが表示されるので、**[OK]** をタップします。
