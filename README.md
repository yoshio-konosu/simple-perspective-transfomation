# シンプル台形補正
　直感的に扱えるシンプルなアプリ。
　斜めから映した写真を正面から撮ったように補正します。

## 【やり方】

１．
&nbsp; 📱 画面下部の [Select] から写真または動画を選んでください。（ボタン：Select）

２．
&nbsp; 【写真の時】

&nbsp; 選択した写真が表示されたら、[Edit]ボタンを押して次に進みます。（ボタン：Edit）
 
&nbsp; 【動画の時】

&nbsp;　　 ▶️ 動画を再生し、ベストな瞬間で [Capture] を押してください。（ボタン：Capture）
&nbsp;　　 切り出した場面が表示されます。[Edit]ボタンを押して次に進みます。（ボタン：Edit）
&nbsp;　　 やり直す時は、[Discard]ボタンを押してください。（ボタン：Discard）

３．
&nbsp; 🎯 4つの照準を合わせて、右上の [Crop] を押してください。

4．
&nbsp; 補正された画像が表示されます。（ここで、再度補正が必要な場合は、前項２、から繰り返します。）

5．
&nbsp; 🖼️ ドラッグして縦横の比率を自由に調整できます

6．
&nbsp; 完成した画像を保存します。（ボタン：Save）

7．
&nbsp; ”画像の保存に成功しました”アラートが表示されるので”OK”タップします。
